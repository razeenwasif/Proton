Circuit

          
Draw gates, flip-flops, memories and buses, run them, and check them against test tables. A project is kept as a .circuit folder of text that diffs: a .circ file a circuit, a line a part or wire. Logic

          
A calculator and a solver for logic. Write a formula or an argument on a line beginning ? — ? p, p -> q |= q — and the line at the cursor is answered: its truth table, whether it is a tautology, its normal forms, its Karnaugh map. Theories of sorts, names and constraints are written the same way, and Logic for Fun's .l4f text is read as it is. A .proof file is a natural-deduction proof, Fitch style, each line checked against its rule — or found.

CAD

          
Parts drawn exactly. A part is a sketch or two — lines, arcs and circles held by constraints and dimensions — extruded or revolved into solids, each step in order on the left and each kept in a .part file that reads as text and diffs in Git. Draw on a plane with the mouse, type a dimension in place, and the solver says what is still free; the solids are checked closed and written as STL or 3MF for a printer.

Appearance

      

        
Workspace theme

        
Choose the colors used throughout Proton.

        

          
          
          
          
          
          
          

        

      


      
      

        
Plugins

        
Wasm components, sandboxed and on a deadline. A plugin that will not finish a call is stopped rather than allowed to take the window with it. They live beside your session, not in a project — a repository cannot bring code with it.

        

      

      

        
Window background

        
Mica takes its colour from your wallpaper — the compositor samples it, so the whole window tints as you move it across the desktop. Acrylic blurs whatever is actually behind the window, live, and costs more. Content surfaces stay opaque either way: code is never at the mercy of a wallpaper.

        

          
          
          
          
          
        

        

      

      

        
Translucency

        
Choose how much of the window background shows through. Subtle gives text the strongest contrast.

        

          
          
          
        

      

      

        
Interface text

        
Make labels, menus, and messages easier to read. Editor text has its own size below.

        
      

      

        
Density

        
Choose more breathing room or fit more rows on screen.

        
      

      

        
Surface blur

        
Soften the content behind floating panels, including this window.

        
      

      

        
Editor text

        
Codex uses JetBrainsMono Nerd Font when it is installed, and the terminal follows the editor's size. The other modes use CaskaydiaMono, with your system monospace font as a fallback.

        
      

      

        
File tabs

        
Codex shows the open file's path above the code instead of a row of tabs. ␣fb lists the open buffers either way.

        
      

      

        
Terminal

        
The GPU draws the terminal the way Zed does: each character is drawn once, and a busy screen is redrawn without laying out any text. It is new, so text stays the default. Selecting and copying work the same with either.

        
      

      


      

        
Editing

        
Keyboard navigation
In the file tabs, use ← / → or Home / End to move focus, Enter to open, and Delete to close. Unsaved files stay open. Tab to a split divider and use arrow keys to resize, Shift for larger steps, or Home to make the two panes equal. Esc returns to the editor.

        
Modal editing
Proton uses Vim-style editing in every mode. Press i to insert, Esc to return to Normal mode, and Space for the leader menu. A non-modal editing mode is not available yet.

        
Undo and redo
In Codex, use the pane’s Undo and Redo buttons, or ⌘Z and ⇧⌘Z on Mac (Ctrl+Z and Ctrl+Shift+Z or Ctrl+Y on Windows/Linux). In Normal mode, u undoes and Ctrl+R redoes. Continuous typing is one undo step; moving the cursor or saving starts a new step.

        

          
Format on save

          
`:w` writes the file and then asks the language server to format it, writing again if anything changed. Turn this off for a project whose formatter disagrees with its own history.

          
          
        

      


      

        
AI & models

        

          
Provider

          
Which service the agent pane talks to. The key to reach it with is never stored here — it comes from the environment, or from that provider's own CLI login.

          

            
            
            
            
          

        

        

          
Model

          
Left blank, each provider uses its own default — the careful model for agent work, a small fast one for completion.

          
        

        

          
Credential

          
Checking…

          
Codex uses your existing Codex sign-in. Sign in through the Codex app or run codex login, then send a message here. GPT-6 Astra is the default for Codex.

          
Antigravity uses your Google sign-in through its agy command, so a Gemini subscription works without an API key. Run agy once in a terminal to sign in. Gemini 4 Argon (High) is the default; agy models lists the rest.

        

        

          
Writing files

          
On, the agent creates and changes files in the project as it works, and each change can be undone from its row in the agent pane. Off, Claude, Gemini and Codex stage their changes for you to review in the editor, and Antigravity only reads. Either way nothing is written outside the project, and a file with unsaved changes of yours is staged rather than written.

          
          
          
Antigravity works with its own tools, and files it changes are re-read when it finishes. It cannot stop to ask before running a command, so it gives you the command to run instead.

        

      


      

        
Library

        

          
Roots

          
Directories of your own writing — a vault, course notes, a papers folder — that the agent may search and cite. Nothing is read until you list it here, and nothing outside a listed directory is ever read: no symlink is followed out of one, and hidden folders and anything .gitignore excludes are skipped.

          

          

            
            
          

        

        

          
Sources

          
Which parts of the library a question may draw on. Nothing ticked means all of it. Narrowing is worth doing when a question belongs to one subject: matching is by word rather than by topic, so the same term reaches every field that uses it — convergence finds optimisation, training and numerical methods at once.

          

          
        

        

          
PDFs

          
Papers, slide decks and textbooks, read a page at a time and cited by page — clicking one opens it in Proton's viewer at that page. Getting the text out is slow: 240 documents took three and a half minutes the first time. It is kept afterwards, so only a new or edited document costs anything. A scan with no text layer is skipped rather than indexed as noise.

          
        

        

          
What has been read

          
Notes are searchable as soon as they are read; the PDFs land after. The roots are checked for changes every twenty seconds — a stat-only look that costs about 180 ms over 36,000 files — and re-read when something moved. What is already indexed stays searchable throughout.

          
No roots listed.

          
          
        

        

          
Meaning

          
Matching by word finds a passage only when it uses the words you did. Why is my loop slow when the array is big shares no term with a section on cache blocking, so it cannot reach it — no amount of tuning changes that. Naming a local embedding model here adds a second ranking by meaning and fuses the two, which does reach it.

          
It runs on your machine through ollama, so nothing leaves it and nothing is billed. The cost is time: it embeds about 60 passages a second, so a vault of 16,000 takes four or five minutes the first time. What it makes is kept, and keyed on the text of the passage rather than on where it lives — so re-reading a file, or moving one, costs nothing. Leave it empty for words only, which is a complete answer and a narrower one.

          
          
ollama pull embeddinggemma gets one. A question is embedded when the agent searches, which adds about two seconds to that one call; the ␣fl picker stays on words, because two seconds a keystroke is not a picker.

        

        

          
Citing

          
Answers quote a passage's citation in double brackets — [[Attention.md § Sparse patterns L42-58]] — which is clickable in the agent pane and is a working link if you paste the answer back into Obsidian.

        

      


      

        
Plugins

        

          
Installed

          
Loaded from the project when the session starts. Installing one needs a restart, so this is what is running now rather than what is on disk.

          

        

      


      

        
Configuration

        

          
Where settings live

          
A file in the project, beside .proton/debug.json, so it diffs and can be committed if the team wants the same editor. Keys this build does not recognise are left alone.
